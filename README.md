# KRAS G12D ML Screening Pipeline Validation

This repository contains code and processed analysis outputs used for the MSc dissertation project:

"Validation of an ML Screening Pipeline for KRAS G12D Ligands"

The repository includes:

1. Representative ligand subset analysis from Myriad screening outputs.
2. Structural analysis and PyMOL visualisation files.
3. Validation of the old Random Forest model against improved ligand-in-QM/MM barriers.
4. Feature importance and variance diagnosis.
5. Reduced-feature high/low transfer testing.

The full molecular structures, QM/MM outputs, trained model files and large intermediate files are not included due to file size and project data restrictions. This repository is intended to document the analysis workflow and processed outputs used in the dissertation.
